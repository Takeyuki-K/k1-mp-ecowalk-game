HOW TO PLAY

操作説明

キー操作
W / ↑ を押し続けると前進。A / D または ← / → で旋回。離すと停止。Shiftを押しながら前進すると4.0m/s。− / ＋または速度ボタンで通常速度を変更。
停止・視点
Space：停止、B：急停止、C：一人称／三人称、Esc：停止してメニュー。
ジョイスティック
画面のパッドをドラッグ。上が前進、左が左旋回、右が右旋回。離すと停止。USBゲームパッドはチェックを入れ、ボタンを押して接続してください。標準マッピングの左スティック、A停止、B急停止に対応。
コースマップ
上から見た全体図です。黄色の矢印が現在位置と向き、緑がゴール、灰色が壁と障害物。右が進行方向のX軸です。
ゴール
緑の範囲内で止まり、停止状態を1秒維持するとゴール。足を揃えるまで少し待つ場合があります。
スコア
ゴールまでの総消費Whが少ないほど高得点。障害物に衝突すると減点。転倒・範囲外・時間切れは失敗。

後退・横移動は未学習。旋回時は安全のため自動減速します。
